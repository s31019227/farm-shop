# 🌾 農場 × 小店 🏪

多人即時合作的種田 + 開店網頁遊戲（最多 4 人）。電腦、iPhone、Android 都能用瀏覽器玩。

**線上玩：** https://s31019227.github.io/farm-shop/

## 怎麼開始

1. 一個人按「建立房間」當房主，畫面上方會出現 4 碼房間代碼。
2. 其他人打開同一個網址，輸入代碼按「加入」（或直接點房主傳的邀請連結）。
3. 大家在準備畫面取名字、選顏色、按「準備好了」，房主按「開始遊戲」。

房主的電腦跑遊戲邏輯，其他人用 [PeerJS](https://peerjs.com/) 點對點連過來，不需要另外架伺服器。
房主關掉遊戲後，重新打開按「接續上次的農場」，大家會自動接回來。

## 在自己電腦跑

```
node server.js
```

然後打開 http://localhost:8080 。同一個 Wi-Fi 的手機可以用視窗上列出的區網網址。

## 檔案

| 檔案 | 內容 |
|---|---|
| `sim.js` | 遊戲規則和模擬（作物、加工、客人、訂單、季節、升級、目標） |
| `render.js` | 畫面繪製 |
| `main.js` | 大廳、連線、介面、音效、存檔 |
| `sw.js`、`manifest.webmanifest` | 安裝成 App（PWA）和離線快取 |
| `server.js` | 本機測試用的小伺服器 |
